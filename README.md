# 公众号运营系统（gzh-ops）

三大入口，一个系统：

| 入口 | 路径 | 用途 |
|---|---|---|
| 🧭 7步创作流水线 | `pipeline.html` | 确定题材 → 爆款分析 → 保存选题 → 润色标注 → 合规去AI → 专业排版 → 封面Canva |
| ✍️ AI写作工作台 | `writer/index.html` | 选题库 / 知识库 / 写稿 / 配图 / 复盘（本地为主） |
| 🏠 老站（全功能） | `booster/index.html` | gzh-booster 原站：竞品样本、数据分析、标题工坊、排版、策略（Supabase 云同步） |

## 数据说明
- 流水线与老站共用同一 Supabase 云（`gzh_sync` 表）：任一站点的 ☁️ 设置里填同一个同步码，数据即互通。
- 写作工作台为本地存储（`gzh_` 前缀 localStorage），可用应用内备份文件迁移。

## 本地预览
静态站点，任意静态服务器均可，例如：
```
python -m http.server 8080
```
